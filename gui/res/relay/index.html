Troubleshooting: Alternative Login Method

If you're having trouble with the login page, you can use this alternative method:

  1. Login to your Sony account in any browser on any platform (mobile device, tablet, computer, etc.) - just make sure you're logged into your Sony account in the browser.
  2. After logging in, open this URL in your browser:
    https://ca.account.sony.com/api/v1/ssocookie
  3. Copy the npsso code that appears on that page (it will be in JSON format like {"npsso":"your-token-here"})
  4. Return here and proceed to Step 3: Paste NPSSO Token to paste the code
Note: This method allows you to skip the OAuth login flow and directly obtain your NPSSO token from any browser where you're already logged into your Sony account.
